Privacy Policy

Last updated: November 6, 2026

About This Application

Oracle VPS Backups is a privately operated application used to back up and restore files between a personal cloud server and Google Drive.

Google Drive Access

The application uses Google OAuth authorization to access Google Drive for storing, managing, and restoring backup files.

Data Storage and Security

Backup files are encrypted before being uploaded to Google Drive. Authentication credentials are stored privately on the server.

Data Sharing

The application is intended for personal use. It does not sell or share Google user data with third parties.

Data Control

The Google account owner can revoke access through their Google Account security settings and delete backup files from Google Drive.
