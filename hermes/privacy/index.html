Privacy Policy for Hermes AI Workspace

Google data access and use

Hermes AI Workspace connects to the operator's dedicated Google account to carry out Workspace tasks. Google OAuth permissions govern its access to Gmail messages, Drive files, Calendar events, Docs documents, and Sheets spreadsheets.

Storage, protection, and retention

Hermes stores its Google authorization token on the privately operated server so it can reconnect to Google. Google data saved by Hermes on the server has no automatic expiration and is kept until the operator deletes it.

AI processing and data sharing

Hermes uses OpenRouter for AI processing. When a Workspace task includes Google data in the model request, OpenRouter and the model provider it routes to receive that data to generate a response. This can include email content, file details, calendar events, document text, or spreadsheet values used for the task. Retention depends on the routing settings and the model provider. See OpenRouter's privacy policy and its data collection documentation.

Revoking access and deleting data

The operator can revoke Hermes access in Google Account connections. To remove Google data already saved by Hermes, the operator can delete the stored copies from the server.
